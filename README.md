# 🔬 Scientific Calculator – C++ & Qt 6

A modern Scientific Calculator developed using **C++, Qt 6, and Qt Designer**. This desktop application provides basic arithmetic operations along with advanced scientific calculations through a clean and user-friendly interface.

## 🚀 Features

- Basic arithmetic operations (+, −, ×, ÷)
- Square and square root
- Power and factorial calculations
- Trigonometric functions (sin, cos, tan)
- Hyperbolic functions
- Logarithmic functions (log and ln)
- Degree and Radian modes
- Brackets and expression evaluation
- Scientific notation (EXP)
- Fraction conversion
- Memory operations
- SHIFT and ALPHA functionality
- Numerical integration
- Error handling for invalid calculations

## 🛠️ Technologies Used

- **Programming Language:** C++
- **Framework:** Qt 6
- **UI Design:** Qt Designer
- **Build System:** CMake
- **IDE:** Qt Creator

## 📸 Project Overview

The application features a scientific calculator interface designed to make mathematical calculations easier and more accessible.

## ⚙️ How to Run

1. Clone this repository.
2. Open the project in Qt Creator.
3. Configure the project using CMake.
4. Build the project.
5. Run the application.
